# API-документация

---

Здесь представлен пример API-документации на основе учебного сервиса Petstore (интернет-магазин для животных). Это демонстрация того, как выглядит интерактивная документация, созданная с помощью Swagger UI и OpenAPI-спецификации.

---

- Посмотреть список всех доступных эндпоинтов.
- Узнать, какие параметры принимает каждый запрос.
- Отправить тестовый запрос прямо из браузера.
