# Описание ошибок

Petstore API возвращает стандартные HTTP-коды ошибок.

## Коды ошибок

| Код | Описание |
| :--- | :--- |
| 400 | Неверный запрос. Например, передан неверный ID или формат данных. |
| 404 | Ресурс не найден. Например, питомец с указанным ID не существует. |
| 405 | Метод не разрешён. Например, использование GET вместо POST. |
| 500 | Внутренняя ошибка сервера. |

## Примеры

### 404 — Pet not found

При запросе `GET /pet/999999` (если такого питомца нет) сервер вернёт:

```json
{
  "code": 1,
  "type": "error",
  "message": "Pet not found"
}
```
### 400 — Invalid ID supplied

Если передан неверный формат ID, сервер вернёт ошибку 400 с соответствующим сообщением.

```json
{
  "code": 400,
  "type": "error",
  "message": "Invalid ID supplied"
}
```

## Рекомендации

- Проверяйте, что ID питомца существует.

- Убедитесь, что тело запроса соответствует схеме.

- Используйте корректные HTTP-методы для каждого эндпоинта.
