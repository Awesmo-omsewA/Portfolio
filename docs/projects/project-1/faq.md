# Часто задаваемые вопросы

## Как получить список питомцев по статусу?

Используйте `GET /pet/findByStatus?status=available`.

## Как создать заказ?

Используйте `POST /store/order` с телом, содержащим `petId` и `quantity`.

## Нужен ли API-ключ для работы с Petstore?

Для большинства запросов ключ не требуется. Для удаления питомца (`DELETE /pet/{petId}`) требуется заголовок `api_key` — в учебном API можно передать любое значение.

## Почему запросы через Swagger UI не работают?

Возможная причина — CORS. Petstore не разрешает запросы с некоторых доменов. Для тестирования используйте Postman или включите расширение для отключения CORS в браузере.

## Можно ли использовать Petstore в реальных проектах?

Нет, это учебный API. Он не хранит данные между сессиями.
