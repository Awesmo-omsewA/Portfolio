# Быстрый старт

В этом руководстве вы узнаете, как быстро начать работать с Petstore API.

## Шаг 1. Откройте документацию

Перейдите на страницу интерактивной документации:

👉[API-документация](/Portfolio/api-doc/index.html)

Там вы увидите все доступные эндпоинты и сможете отправлять тестовые запросы прямо из браузера.

## Шаг 2. Выполните первый запрос

1. В разделе `pet` найдите эндпоинт `GET /pet/{petId}`.
2. Нажмите **Try it out**.
3. Введите `1` в поле `petId`.
4. Нажмите **Execute**.

Сервер вернёт данные питомца с ID = 1 в формате JSON.

## Шаг 3. Попробуйте создать нового питомца

1. Найдите эндпоинт `POST /pet`.
2. Нажмите **Try it out**.
3. В поле **Request body** вставьте:

```json
{
  "id": 999,
  "name": "Арчи",
  "status": "available"
}
```

Нажмите Execute.

Сервер вернёт созданный объект питомца.

## Шаг 4. Что дальше

Изучите остальные эндпоинты и попробуйте другие методы: PUT, DELETE.
