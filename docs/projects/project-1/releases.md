# Release Notes

## Версия 1.0 (текущая)

**Дата:** 2025

**Что включено:**
- Базовый функционал управления питомцами (создание, чтение, обновление, удаление).
- Заказы и инвентаризация.
- Управление пользователями.
- Интерактивная документация через Swagger UI.

**Известные ограничения:**
- API не сохраняет данные между сессиями.
- CORS-ограничения при отправке запросов из браузера.
