# Проект 1: Petstore

**Petstore** — это учебный REST API интернет-магазина товаров для животных. В рамках этого проекта я подготовил полный комплект документации, который охватывает все аспекты работы с API: от быстрого старта до справочника эндпоинтов и обработки ошибок.

---

## Состав документации

Проект включает следующие документы:

- **[Быстрый старт](quickstart.md)** — как получить доступ и отправить первый запрос.
- **[Руководство пользователя](guide.md)** — основные сценарии работы с API.
- **[Руководство по установке](installation.md)** — настройка окружения для локального тестирования.
- **[API-документация](../../api-doc/)** — интерактивный справочник всех эндпоинтов (Swagger UI).
- **[Описание ошибок](errors.md)** — коды ответов и их причины.
- **[FAQ](faq.md)** — ответы на частые вопросы.
- **[Release Notes](releases.md)** — история изменений и версий.

---

## Технологии

- **OpenAPI 2.0** — спецификация API. 
> В проекте еще Swagger 2.0, а не OpenAPI 3.0
- **Swagger UI** — интерактивная документация.
- **MkDocs** — сборка и публикация сайта.
