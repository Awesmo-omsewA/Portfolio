# Проект 1: Документация к GitHub API

Этот проект находится в стадии подготовки. Здесь будет пример документации к открытому API (например, GitHub API).

**Что будет включено:**
- Быстрый старт.
- Руководство пользователя.
- API-документация (Swagger UI).
- FAQ.

**Планируемые технологии:** OpenAPI, Swagger UI, MkDocs.
