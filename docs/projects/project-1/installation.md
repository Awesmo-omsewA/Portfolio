# Руководство по установке

Petstore — это публичный учебный API, который не требует установки. Он доступен по адресу:

`https://petstore.swagger.io/v2/`

Для локального тестирования вы можете использовать любой HTTP-клиент (например, Postman или Swagger UI).

## Настройка окружения

1. Откройте страницу [API-документация](https://awesmo-omsewa.github.io/Portfolio/api-doc/) на этом сайте.
2. Используйте Swagger UI для отправки запросов.

Или используйте Postman:

1. Импортируйте спецификацию OpenAPI из файла `petstore.json`.
> Вы можете скачать OpenAPI-спецификацию по ссылке:  
>[https://petstore.swagger.io/v2/swagger.json](https://petstore.swagger.io/v2/swagger.json)
1. Отправляйте запросы к серверу.

## Требования

- Браузер или Postman.
- Доступ в интернет (API работает удалённо).
