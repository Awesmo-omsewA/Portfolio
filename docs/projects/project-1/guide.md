# Руководство пользователя

Это руководство описывает основные сценарии работы с Petstore API.

## Получение информации о питомце

Используйте запрос `GET /pet/{petId}`, чтобы получить данные питомца по его ID.

**Пример:**
- `GET /pet/1` — вернёт питомца с ID = 1.

**Ответ:**
```json
{
  "id": 1,
  "name": "doggie",
  "status": "available"
}
```

## Добавление нового питомца

Используйте запрос POST /pet с телом в формате JSON.

**Пример тела запроса:**

```json
{
  "id": 999,
  "name": "Барсик",
  "status": "available"
}
```

**Ответ:**
Сервер возвращает созданный объект питомца.

## Обновление питомца

Используйте PUT /pet с обновлёнными данными в теле запроса.

**Пример:**

```json
{
  "id": 999,
  "name": "Барсик",
  "status": "sold"
}
```

## Удаление питомца

Используйте DELETE /pet/{petId}. Требуется заголовок api_key (учебный API позволяет любой ключ).

## Работа с заказами
Эндпоинты в разделе store позволяют создавать заказы (POST /store/order) и проверять инвентарь (GET /store/inventory).

## Управление пользователями
Раздел user содержит эндпоинты для создания, получения, обновления и удаления пользователей.
