# Выбор инструментов

Для создания портфолио я выбрал следующие инструменты:

- **MkDocs** — генератор статических сайтов на Python. Прост в настройке, поддерживает темы и плагины.
- **Git и GitHub** — контроль версий и хостинг репозитория.
- **GitHub Pages** — бесплатный хостинг для статических сайтов.
- **GitHub Actions** — CI/CD для автоматической сборки и деплоя.

Почему именно они?  
- MkDocs и Material — стандарт в сообществе Docs as Code.
- GitHub Pages и Actions — бесплатно, интегрированы с Git, надёжны.
