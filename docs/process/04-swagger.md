# Интеграция Swagger UI

**Swagger UI** — это инструмент для визуализации и интерактивного тестирования API. Он превращает OpenAPI-спецификацию в удобную документацию, где можно не только читать, но и отправлять тестовые запросы прямо из браузера.

> В портфолио для демонстрации API-документации с  использованием Swagger UI есть пример Petstore. Учебный сервис для интернет-магазина товаров для животных.
>
[API-Документация](/api-doc/)

---

## Подключение

Чтобы добавить Swagger UI на сайт, я использовал плагин <br> `mkdocs-swagger-ui-tag`.

### Установка

```bash
pip install mkdocs-swagger-ui-tag
```
> Команда в терминале

### Настройка в mkdocs.yml

Добавил плагин в список:

```yaml
plugins:
  - search
  - swagger-ui-tag
```

### Добавление страницы

В папке docs/ я создал файл api.md и вставил тег с ссылкой на OpenAPI-файл:

```html
<swagger-ui src="petstore.json"/>
```

OpenAPI-файл (petstore.json) лежит в той же папке docs/.

## Результат

На сайте появилась страница /api, на которой отображается интерактивная документация API:

список всех эндпоинтов;

методы запросов (GET, POST, PUT, DELETE);

параметры и схемы данных;

возможность отправлять тестовые запросы.

Это делает документацию полезной не только для чтения, но и для практической проверки API.
